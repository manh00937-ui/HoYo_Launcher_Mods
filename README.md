# 3DMigoto-Launcher-Mod
Launcher quản lí mod của 3dmigoto
Launcher được phát triển trên nền WinUI3 cực mới của window, ăn khoảng 80-100mb ram cực nhẹ nên máy yếu xài thoả mái

CÁCH CÀI:

Tải file 3dmigoto launcher trên về    

Giải nén đến thư mục riêng ( ko nên để trong Dowloal vì dễ xóa nhầm hoặc thất lạc)

Mở file giải nén ra và chạy file 3D Migoto Launcher.bat

Mở setting

Bấm Quét tự động để launcher quét và tìm vị trí các file cài đặt
